# Authentication Logs

Authentication logs record login and authentication activity.

## Important Fields
- Timestamp
- Username
- Source IP
- Destination Host
- Event ID
- Logon Type
- Authentication Result
- Workstation

## Use Cases
1. Failed login
2. Brute force
3. Password spraying
4. Successful login after failures
5. Suspicious login
6. Privileged account activity

## Investigation Questions
- Who authenticated?
- From where?
- To which host?
- When?
- How many attempts occurred?
- Was authentication successful?
- What happened immediately afterward?
