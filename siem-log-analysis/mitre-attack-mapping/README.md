# MITRE ATT&CK Mapping

Map each detection to the most appropriate ATT&CK technique based on the actual behavior observed.

## Example Mapping
- Brute Force -> T1110
- Password Spraying -> T1110.003
- PowerShell -> T1059.001
- Network Service Scanning -> T1046
- Remote Services -> T1021
- Application Layer Protocol -> T1071

Always verify technique IDs against the current MITRE ATT&CK knowledge base before presenting a detection as authoritative.
