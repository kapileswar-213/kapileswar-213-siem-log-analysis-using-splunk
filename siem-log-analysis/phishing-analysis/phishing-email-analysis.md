# Phishing Email Analysis

## 1. Email Metadata
Record sender, recipient, subject and timestamp.

## 2. Header Analysis
Review authentication results and mail routing.

## 3. Content
Identify urgency, impersonation, suspicious requests and social engineering.

## 4. Attachments and URLs
Extract and analyze indicators in an authorized environment.

## 5. Endpoint Correlation
Check whether the recipient opened the attachment or visited the URL.

## 6. Response
Quarantine messages, block malicious indicators where appropriate, reset credentials if compromise occurred and document the incident.
