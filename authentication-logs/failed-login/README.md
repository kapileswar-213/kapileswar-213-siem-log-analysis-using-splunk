# Failed Login Analysis

## Objective

Identify and investigate failed authentication attempts.

## Important Information

- Username
- Source IP
- Destination Host
- Timestamp
- Number of Attempts
- Authentication Method

## Investigation Process

1. Identify the affected account.
2. Identify the source IP.
3. Count failed attempts.
4. Check the time pattern.
5. Check whether a successful login occurred afterward.
6. Investigate the source IP.
7. Determine whether the activity is legitimate or malicious.
