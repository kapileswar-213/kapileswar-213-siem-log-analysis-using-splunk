# SIEM Log Analysis & SOC Investigation Lab

## Overview
This repository documents a hands-on SIEM and SOC investigation project covering security log analysis, detection engineering, alert triage, event correlation, threat hunting, MITRE ATT&CK mapping, and incident response.

## Tools
- Splunk
- Microsoft Sentinel
- Splunk SPL
- Microsoft KQL
- Windows Security Logs
- Sysmon
- PowerShell
- Linux Logs
- Firewall Logs
- DNS Logs
- Network Logs

## Project Goals
- Analyze different security log sources.
- Identify attack indicators.
- Create SPL and KQL detections.
- Correlate events from multiple sources.
- Investigate alerts as a SOC analyst.
- Map detections to MITRE ATT&CK.
- Document incident response.

## Investigation Workflow
1. Alert Generation
2. Alert Triage
3. Identify User, Host and IP
4. Review Related Logs
5. Build Timeline
6. Identify IOCs
7. Map MITRE ATT&CK
8. Determine Severity
9. Contain
10. Eradicate
11. Recover
12. Document
